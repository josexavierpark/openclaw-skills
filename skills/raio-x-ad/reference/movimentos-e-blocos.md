# Blueprint persuasivo e blocos canônicos

Referência para a seção 2 (7 camadas + blueprint) e a seção 4 (mapa de blocos) do relatório.

---

## Parte A: Extração do blueprint (movimentos)

O blueprint descreve a **função** de cada movimento, não o conteúdo específico. A pergunta certa não é "o que ele disse aqui?". A pergunta certa é "qual o trabalho persuasivo que essa parte faz na copy?".

- Errado: "Movimento 1: fala que o algoritmo do Meta penaliza anunciantes."
- Certo: "Movimento 1: nomeia adversário externo concreto antes de qualquer promessa. Padrão: [adversário específico] fez [consequência] com [grupo do leitor] sem que [grupo] soubesse."

A descrição precisa ser abstrata o bastante pra aplicar em outro nicho, e específica o bastante pra reproduzir a função.

### Como executar

1. **Leitura completa.** Veja o arco inteiro (frames + transcrição) antes de descrever qualquer movimento.
2. **Identifique os pontos de virada.** Onde o copy muda de modo? Cada virada marca um movimento. Viradas comuns: introdução -> conflito, conflito -> revelação, revelação -> prova, prova -> promessa, promessa -> urgência, urgência -> CTA.
3. **Nomeie cada movimento por função.** Vocabulário curto e funcional ("Nomeação de adversário externo", "Quantificação de consequência física", "Revelação de mecanismo com nome chiclete"). Evite nomes de conteúdo.
4. **Descreva o padrão.** Uma frase com placeholders. Exemplos:
   - `[autoridade nomeada] disse [afirmação] na situação [contexto físico]. Eu [reação cética]. Daí ele [revelou X em voz baixa].`
   - `Você sentia [sintoma A]. Sentia [sintoma B]. Achava que era [causa óbvia]. Verdade: era [causa real escondida].`
   - `[Número quebrado] [unidade] em [período curto] sem [esforço comum esperado].`
5. **Isole a CTA.** Sempre o último movimento, com análise própria nas 4 dimensões.

### Catálogo de movimentos comuns

Use como vocabulário. Não force encaixar todo anúncio nesses tipos exatos.

- **Abertura de tensão:** primeira frase que cria parada, geralmente quebra padrão.
- **Estabelecimento de cena:** coloca o leitor em um momento físico/temporal concreto.
- **Nomeação de adversário:** identifica vilão externo específico.
- **Quantificação de consequência:** número/estatística que materializa o problema.
- **Confissão pessoal:** vulnerabilidade ou erro do narrador em primeira pessoa.
- **Revelação de mecanismo:** explica COMO funciona, idealmente com nome chiclete.
- **Diferenciação:** por que isso é diferente do que o leitor já tentou.
- **Invalidação de solução anterior:** desqualifica o que parecia ser a resposta.
- **Prova específica:** testemunho/dado com nome + número + situação concreta.
- **Antecipação de objeção:** traz a dúvida do leitor à tona e responde.
- **Estabelecimento de autoridade:** credenciais ou validação externa.
- **Promessa pós-prova:** o resultado que o leitor vai ter.
- **Construção de urgência:** razão pra agir agora.
- **Direcionamento ao destino:** como chegar à aula/vídeo/quiz/teste.
- **CTA com gatilho:** comando específico + razão de timing.
- **Validação social via segundo personagem:** entrevistador reage pra confirmar.
- **Loop aberto:** pergunta ou tensão sem resposta imediata pra prender leitura.
- **Detalhe sensorial:** som, imagem, sensação física que ancora a cena.
- **Inimigo visualizado:** descreve o adversário de forma que pode ser sentido fisicamente.

### Quantos movimentos extrair

- Vídeo curto (15-30s): 3-4 movimentos + CTA
- Vídeo médio (60-90s): 4-6 movimentos + CTA
- Roteiro longo/VSL: 8-15 movimentos + CTA
- Roteiro de entrevista: 6-12 movimentos + CTA

Não force quantidade. Se 4 movimentos descrevem tudo, são 4.

### Análise da CTA (4 dimensões)

1. **Como o destino é nomeado:** "aula", "vídeo", "tutorial", "apresentação", "passo a passo", "demonstração"? Em tráfego frio que finge ser orgânico, o destino raramente é chamado de "curso" ou "treinamento".
2. **Que ação é pedida:** "clicar no botão", "tocar em saber mais", "acessar o link", "vir pra próxima página".
3. **Que gatilho de urgência usa:** tempo limitado, escassez de vagas, "vai sair do ar", "só até o fim da semana". Quanto mais específico, mais crível.
4. **Onde aparece:** só no fim ou repetida no meio também? Copy longa costuma repetir 2x. Entrevista vem só no fim.

## Parte B: Estruturas Invisíveis macro (Camada 1)

A Estrutura Invisível nunca fica só no nome. Registre o nome macro **e** a sequência real de blocos (Hook -> ... -> CTA).

| Estrutura | Sequência de blocos |
|---|---|
| Lista | Hook -> Opção 1 fraca -> Opção 2 fraca -> Opção 3 forte -> CTA |
| Erro Comum | Hook -> Erro -> Consequência -> Solução -> CTA |
| História Pessoal | Hook -> Dor passada -> Virada -> Descoberta -> Prova -> CTA |
| The One Thing | Hook -> Problema -> Única solução -> Como funciona -> CTA |
| Alerta Urgente | Hook -> Risco -> Consequência -> Solução -> CTA |
| Conspiração | Hook conspiratório -> Dor -> Autoridade oculta -> Prova -> Invalidação -> Solução -> CTA |
| Invalidação Progressiva | Hook -> Invalida sol.1 -> Invalida sol.2 -> Mecanismo único -> Expert -> Prova -> CTA |
| Podcast/Entrevista | Empilhamento -> Pergunta -> Avatar conta história -> Mecanismo -> Prova -> CTA indireto |

### Não confundir Estrutura x Ângulo x Tema

Vários rótulos (Lista, Erro Comum, História Pessoal, The One Thing, Alerta Urgente, Conspiração, Mecanismo) aparecem em mais de uma camada. Teste rápido: descrevendo a **ordem** dos blocos = Estrutura (C1); o **enquadramento** = Ângulo (C3); o **assunto** = Tema (C6). Os testes completos, com caso real, estão em `classificacao-base.md`, seção 6.

## Parte C: Vocabulário de blocos canônicos (mapa de navegação, seção 4)

Usado no mapa de blocos com timestamps. É um guia de navegação para achar os cortes rápido, ancorado nas falas da transcrição. Não é a classificação estratégica oficial (essa é a Estrutura Invisível macro). As fronteiras podem ser imprecisas.

### Lista rígida (use só estes nomes, na ordem real do ad)

| # | Bloco canônico | O que costuma fazer |
|---|---|---|
| 1 | Hook | Para o scroll nos primeiros segundos, quebra de padrão |
| 2 | Segmentação | Filtra e chama o público-alvo específico ("se você tem mais de 40...") |
| 3 | Teasing | Promete uma revelação sem entregar ainda, abre loop |
| 4 | Prova/Credibilidade | Autoridade, estudo, número, selo, depoimento que sustenta |
| 5 | Dor/Agitação | Aprofunda o problema, mexe na ferida, consequências |
| 6 | Reconhecimento de Descrença | Antecipa o ceticismo e valida ("eu sei que parece mentira") |
| 7 | Mecanismo (tease) | Insinua a causa oculta ou a solução sem abrir tudo |
| 8 | Invalidação | Derruba as soluções que a pessoa já tentou |
| 9 | Benefício | Pinta o resultado, a transformação desejada |
| 10 | Qualificador | Reforça pra quem serve e pra quem não serve |
| 11 | Motivo pra Continuar | Dá razão pra assistir/clicar agora |
| 12 | Push-Pull | Alterna atração e recuo (dá e tira), tensão de desejo |
| 13 | CTA | Comando de ação + destino + gatilho de urgência |

### Blocos de extensão (permitidos, só estes)

- **Perrengue Cobiçado:** o esforço/dor que vale a pena, o preço a pagar que é desejável.
- **Future Pacing:** projeta o espectador no futuro já com o resultado.
- **Bullets:** enumeração rápida de benefícios ou provas em sequência.
- **Grupo/Exclusividade:** senso de comunidade, clube, acesso restrito.

### Regras

1. Só estes nomes. Não invente nomes descritivos. Nem todo ad tem todos os blocos: inclua só os que existem, na ordem real (a ordem da lista é típica, não obrigatória).
2. Cena que cobre dois blocos sem corte nítido: marque os dois separados por barra (ex: "Dor/Agitação / Mecanismo (tease)"). Nunca crie um terceiro nome.
3. Timestamps ancorados nas falas reais da transcrição (`transcript.json` do Groq), não em tempos aproximados de cena.
4. Para cada bloco, sempre as primeiras 5-7 palavras E as últimas 5-7 palavras. Nunca omita a última fala (evita a emenda cega entre blocos).
