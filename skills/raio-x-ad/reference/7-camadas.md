# Bancos completos das 7 Camadas Macro

Referência de classificação para o analista de anúncios. Use estas tabelas para escolher a opção certa em cada camada e para reconhecer o tema concreto de um anúncio pelos exemplos por nicho.

Os exemplos de tema são âncoras de reconhecimento, não uma lista fechada. Servem pra você identificar rápido "isso aqui é um tema de alimento vilão", mesmo quando o anúncio analisado usa outras palavras.

## Visão geral

Todo anúncio de Direct Response que escala opera em 7 camadas simultâneas. Nenhuma camada funciona sozinha. O poder está na combinação.

As decisões pré-copy (formato, avatar, hook, ângulos, fatias de público, ideias centrais) respondem por 80% do sucesso. Definir as 7 camadas antes de escrever é obrigatório para quem cria, e lê-las de volta é o trabalho de quem analisa.

### As 7 camadas

1. **Estrutura Invisível:** o roteiro psicológico (sequência de blocos que conduz ao clique).
2. **Formato:** embalagem visual (UGC, Podcast, Notícia, etc.).
3. **Ângulo:** ponto de vista (Lista, Erro Comum, Conspiração, etc.).
4. **Fatia de Público:** segmento específico que o ad quer atingir.
5. **Avatar:** quem aparece (segmentação visual + amplificador emocional).
6. **Tema:** assunto do anúncio (alimento, celebridade, descoberta, erro, tendência, conspiração, etc.).
7. **Nível de Consciência:** estágio de entendimento das pessoas sobre o problema ou a solução.

## Camada 1: Estrutura Invisível

O roteiro psicológico que conduz do hook ao clique. A mesma Estrutura Invisível pode ser usada com diferentes formatos, ângulos, fatias, avatares, temas e níveis de consciência.

Nunca registre só o nome. A Camada 1 vai sempre como `Nome | Hook → ... → CTA`, com a sequência real observada no anúncio.

### Estruturas macro (opções)

| Estrutura | Sequência de blocos |
|---|---|
| Lista | Hook → Opção 1 fraca → Opção 2 fraca → Opção 3 forte → CTA |
| Erro Comum | Hook → Erro → Consequência → Solução → CTA |
| História Pessoal | Hook → Dor passada → Virada → Descoberta → Prova → CTA |
| The One Thing | Hook → Problema → Única solução → Como funciona → CTA |
| Alerta Urgente | Hook → Risco → Consequência → Solução → CTA |
| Conspiração | Hook conspiratório → Dor → Autoridade oculta → Prova → Invalidação → Solução → CTA |
| Invalidação Progressiva | Hook → Invalidar sol.1 → Invalidar sol.2 → Mecanismo único → Expert → Prova → CTA |
| Podcast/Entrevista | Empilhamento → Pergunta → Avatar conta história → Mecanismo → Prova → CTA indireto |

## Camada 2: Formato

Formato é amplificador emocional. Formato familiar ao público gera engajamento, o que faz o Meta baratear CPM e CPC e aumentar conversão.

### Opções de formato

| Formato | Descrição |
|---|---|
| Andando na Rua | Pessoa filmando enquanto caminha, tom casual e orgânico |
| Ator/Atriz na Tela | Pessoa falando direto pra câmera (talking head) |
| Caixinha de Perguntas | Simula resposta a pergunta do Instagram Stories |
| Cinematográfico | Produção alta, cortes cinematográficos, trilha sonora |
| Dentro do Carro | Tom íntimo e casual, como se contasse um segredo |
| Fofoca/Confessional | Estilo "te conto um segredo", voz baixa, close íntimo, proximidade |
| Podcast | Conversa/entrevista em estúdio, microfone visível, intimidade |
| React | Reagindo a outro vídeo ou conteúdo viral |
| Receitinha | Mostrando preparo de receita/mistura, formato tutorial |
| Se Maquiando | Casual, arrumando-se enquanto fala |
| Tela Dividida | Antes/depois, comparação, avatar + receita |
| UGC | Parece vídeo caseiro de usuário real, orgânico |
| Entrevista | Pergunta e resposta com 2+ pessoas |
| Notícia/News | Estilo jornalístico, breaking news, headline vermelha |
| Reels/TikTok | Vertical, cortes rápidos, trends |
| Wiki-How/Tela Branca | Fundo branco com texto e imagens ilustrativas |
| Hack do Corpo | Demonstra truque físico no próprio corpo |
| Slideshow com Narração | Sequência de imagens/telas com voz sobreposta, sem cena filmada |
| Animação | Motion graphics, ilustração animada, sem pessoa real |

Quando dois formatos convivem (ex: UGC vertical com tarja de telejornal), escolha o que domina a embalagem e anote o secundário. As pistas visuais que levam a cada formato estão em `pistas-visuais.md`.

## Camada 3: Ângulo

Ângulos podem ser combinados (ex: Contrarian + Mecanismo, Conspiração + História Pessoal). Liste todos os que operam no anúncio, não só o principal.

### Opções de ângulo

| Ângulo | O que faz |
|---|---|
| Pergunta Paradoxal | Desafia lógica ou crença popular com pergunta que não faz sentido até fazer |
| Nova Descoberta | Anuncia novidade exclusiva, estudo recente, atualização |
| Fofoca/Segredo | Explora curiosidade por informação proibida ou secreta |
| Quick & Fast | Promete solução rápida, fácil, sem esforço |
| Antes e Depois | Mostra transformação extrema com contraste visual |
| Alerta Urgente | Desperta urgência por risco, perigo ou consequência grave |
| The One Thing | Uma única coisa resolve tudo, simplificação máxima |
| Erro Comum | Revela erro que o prospect comete sem saber e que prejudica |
| Violação de Expectativa | Entrega o oposto do esperado, quebra padrão mental |
| Predição | Antecipa consequência futura se não agir agora |
| Tips & Tricks | Dica prática de especialista, tom educacional |
| Conspiração | Algo está sendo ocultado pela indústria/governo/sistema |
| Lista | Estrutura numerada (3 ferramentas, 5 erros, 7 segredos) |
| Prova Social | Testemunho extremo, números de pessoas, viralização |
| História Pessoal | Jornada de transformação do avatar ou de terceiro |
| Contrarian | Vai contra o senso comum, diz o oposto do esperado |
| Mecanismo da Solução | Explica como a solução funciona (causa-efeito) |
| Mecanismo do Problema | Revela a causa oculta/raiz do problema |
| Curiosidade Absurda | Promessa tão absurda que obriga o clique pra verificar |
| Medo e Consequências | Usa medo de consequências graves se não agir |

Ângulos que aparecem com frequência nos exemplos de tema e valem como rótulo: **Superestrutura** (empresta uma estrutura cultural pronta: celebridade, país, tradição, profissão), **Comparação** (mede a solução contra um tratamento caro ou famoso), **Escassez**, **Insider** (fonte de dentro que vazou), **Metáfora** e **Receita**.

## Camada 4: Fatia de Público

A segmentação mais poderosa costuma ser indireta, via situações da rotina, não declaração direta para a pessoa. Deduza a fatia pela cena retratada, não pela frase "se você é mulher acima de 40".

### Fatias: Saúde em geral

| Fatia | Dor / Desejo |
|---|---|
| Mulher que tentou de tudo | Frustrada com dietas, remédios, tratamentos que falharam |
| Mãe que quer cuidar dos filhos | Quer energia, não quer ser peso pra família |
| Mulher na menopausa | Ganho de peso, calores, insônia, hormônios |
| Cuidadora de familiar doente | Filha/esposa de pai/mãe/marido com Alzheimer, diabetes |
| Homem 60+ com medo de declínio | Memória, energia, virilidade, medo do asilo |
| Homem com ED que esconde | Vergonha, masculinidade ameaçada |
| Endividado com tratamentos | Gastou em médicos/remédios sem resultado |
| Desconfia de Big Pharma | Cético, busca soluções naturais/caseiras |

### Fatias: Renda extra

| Fatia | Dor / Desejo |
|---|---|
| Mãe que quer ficar em casa | Ganhar dinheiro sem largar filhos |
| CLT cansado | Largar patrão, liberdade de tempo |
| Desempregado | Renda sem currículo ou experiência |
| Endividado | Pagar contas, sair do vermelho |
| Aposentado | Complementar aposentadoria |
| Jovem sem experiência | Ganhar sem faculdade, de casa |
| Tentou de tudo online | Cansada de promessas falsas |
| Pessoa religiosa classe C/D | Mudança financeira, Deus provê caminho |

Nichos fora dessas duas famílias seguem a mesma lógica: nomeie a fatia pela situação de rotina + a dor central (ex: "mãe de bebê que não dorme no berço", "pequeno confeiteiro que vende barato demais").

## Camada 5: Avatar

Dispositivo de segmentação visual + amplificador emocional. Avatar errado + copy certa = conversão baixa. Avatar certo + copy certa = conversão alta.

### Avatar por fatia (Saúde em geral)

- **Mulher comum, mãe:** público feminino classe C/D, donas de casa.
- **Mulher 50+, cuidadora:** filhas/esposas de familiar doente.
- **Homem idoso, trabalhador:** homens 60+, aposentados.
- **Expert de jaleco:** autoridade técnica (diabetes, memória).
- **Mulher IA (ED):** perspectiva feminina, contorna vergonha masculina.
- **Celebridade:** superestrutura de nostalgia pra 55+.

### Avatar por fatia (Renda extra)

- **Mulher comum:** mães, desempregadas, classe C/D.
- **Homem jovem:** público masculino "virar o jogo".
- **Pessoa no carro:** tom casual de segredo.
- **Entrevistada na rua:** reportagem orgânica.

### Sinais de avatar gerado por IA

Mãos com dedos a mais ou a menos, traços que "derretem" entre quadros, piscar antinatural, fundo que muda sozinho, textura de pele cerosa, lábios fora de sincronia. Relevante para marcar "Mulher IA" e para registrar IA em qualquer avatar. Lista completa de tells em `pistas-visuais.md`.

## Camada 6: Tema

O assunto do anúncio. É a ideia que ancora tudo. Pode ser: lista de alimentos, celebridade com transformação, descoberta científica, erro comum, alimento vilão que sabota, conspiração industrial, tendência cultural, comparação com tratamento caro, hábito perigoso, mecanismo oculto no corpo, evento do momento, polêmica/cancelamento, receita caseira, sintoma como alerta de algo pior.

O tema é a camada mais fácil de variar. Com a mesma Estrutura Invisível, formato, ângulo, fatia, avatar e nível de consciência iguais, trocar o tema já cria um anúncio novo que explora mais escala. Um único produto pode ter dezenas de anúncios diferentes apenas variando o tema.

Registre sempre em duas partes: **Tipo de Tema** (a categoria, a coluna esquerda das tabelas) **+ Tema concreto** (o assunto específico daquele anúncio, escrito com as palavras dele).

## Camada 7: Nível de Consciência

Estágio do prospect. Determina tom, estrutura, tipo de lead, nível de promessa, e se o mecanismo vai no hook ou no corpo.

### Os 5 níveis (Schwartz)

| Nível | O prospect... | Como a copy se adapta |
|---|---|---|
| 1 - Totalmente Inconsciente | Não sabe que tem problema | Curiosidade pura ou situação cotidiana. Nunca agressivo. |
| 2 - Consciente do Problema | Sabe que tem, não conhece solução | Dores diretas. Solução educativa. Hook direto na dor. |
| 3 - Consciente da Solução | Sabe que existem soluções, não achou a certa | Cético. Mecanismo sério. Quebrar objeções. Hook = nova descoberta. |
| 4 - Consciente do Produto | Conhece o tipo de produto | Diferenciais, prova, oferta. Hook = o que torna este diferente. |
| 5 - Mais Consciente | Já comprou similares | Identidade, pertencimento, oferta irresistível. |

### Como o nível muda o hook

- **Nível 1-2:** curiosidade ou situação cotidiana. Ex memória: "Você já esqueceu o nome do seu neto?" Ex renda: "YouTube quer te pagar."
- **Nível 2-3:** dor direta ou alerta. Ex diabetes: "Este ingrediente estabiliza a glicose?" Ex emag: "Não tome vinagre antes de ver isto."
- **Nível 3-4:** mecanismo novo ou contrarian. Ex memória: "Harvard diz que toxina invisível envenena cérebro." Ex emag: "Sal rosa imita Mounjaro, 50x mais potente."
- **Nível 4-5:** oferta, preço, exclusividade. Ex: "Dr. cobrava $97, mas hoje só aqui nesse vídeo você leva 3 por $100."

Na análise, o nível se lê pelo hook, não pela oferta: curiosidade pura = 1-2; dor direta = 2-3; mecanismo ou contrarian = 3-4; preço e diferencial = 4-5.

## Como tudo se conecta

Estrutura Invisível (base) → Formato (embalagem) → Ângulo (ponto de vista) → Fatia (pra quem) → Avatar (quem aparece) → Tema (assunto) → Consciência (estágio).

Cada camada influencia as outras. Tudo precisa ser coerente. Mudar a fatia pode exigir mudança de avatar. Mudar o nível de consciência pode gerar mudança de tom e ritmo da copy.

## O poder das combinações

Um único produto gera dezenas de ads combinando variações das 7 camadas. Cada variação que muda múltiplas camadas é um novo conceito pro Meta/Andromeda.

Exemplo, mesmo produto de memória pode ter:

- Ad conspiratório em podcast pra homem 60+ (fatia A, tema conspiração pharma).
- Ad de história pessoal em UGC para filha cuidadora 40+ (fatia B, tema sintoma como alerta).
- Ad de lista em formato jornal para casal preocupado (fatia C, tema lista de hábitos perigosos).

Três ads completamente diferentes, mesmo produto.

Na análise, isso vira uma pergunta útil de fechamento: quais camadas esse anúncio manteve do padrão do nicho e qual delas ele trocou? A camada trocada costuma ser a aposta do anunciante.
