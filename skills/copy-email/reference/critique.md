# Fase 5: Critique (scoring do e-mail)

10 heurísticas, 0-4 cada, total 0-40. Tabela com nota, não review solto. Consulte [dna/disguise.md](../dna/disguise.md) para as 7 alavancas.

## As 10 heurísticas

| # | Heurística | Como pontuar |
|---|---|---|
| 1 | Assunto | 0 = clickbait vazio, 4 = curiosidade real + específico |
| 2 | Primeira linha | 0 = genérica, 4 = tensão real, ganha a segunda |
| 3 | Fluidez (linha-única + conectores de fala) | 0 = blocão, 4 = ritmo de fala |
| 4 | Especificidade | 0 = abstrato, 4 = 3+ específicos ancorados |
| 5 | Mecanismo nomeado | 0 = "esse método", 4 = nome chiclete em aspas |
| 6 | Protagonismo do leitor | 0 = "nós oferecemos", 4 = "você" nas frases de valor |
| 7 | Objeção via "Mesmo que…" | 0 = refuta de frente, 4 = transcende |
| 8 | Prova específica | 0 = "muitos clientes", 4 = nome+idade+número |
| 9 | CTA | 0 = "clique aqui", 4 = comando + razão + 1 só |
| 10 | Zero reflexos de IA | 0 = 5+ hits no blocklist, 4 = zero |

## Procedimento
Pontue cada heurística com 1 linha de justificativa. Some.

| Score | Banda | Ação |
|---|---|---|
| 35-40 | Excepcional | Liberar |
| 28-34 | Pronto | Liberar + 1-2 melhorias |
| 20-27 | OK | Liberar + 3-4 melhorias |
| <20 | Crítico | Reescrever |

## Red flags por persona
- **Inbox lotada:** o assunto sobrevive ao lado de 40 outros? A primeira linha (preview) puxa?
- **Cético da lista:** promessa sem âncora? prova sem nome?
- **Leitor no celular:** parágrafos curtos? CTA visível sem rolar muito?
