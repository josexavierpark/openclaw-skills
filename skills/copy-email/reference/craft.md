# Fase 3 e 4: Craft (corpo) e Assunto

Escreve o corpo do e-mail contra o ângulo. O assunto e a primeira linha vêm DEPOIS, na fase 4. Consulte [dna/disguise.md](../dna/disguise.md) para as 7 alavancas.

## Passo 1: Voice Lock

Antes de escrever, uma frase:
```
VOICE LOCK: [tempo verbal] + [posição do leitor] + [registro: bar/conversa] + [narrador]
```

## Passo 2: Corpo (estrutura por objetivo)

Cada linha ganha a próxima. Ritmo linha-única. Burstiness: alterne curta e longa.

### Broadcast de oferta (150-300 palavras)
```
[ASSUNTO: rascunho]
[Abertura: o arquétipo escolhido na fase 2] (1-3 linhas)
[Tensão / problema dimensionado] (2-4 linhas)
[Mecanismo nomeado em aspas] (2-3 linhas)
[Prova específica: nome + idade + número, ou placeholder] (1-2 linhas)
[Ponte pro destino] (1 linha)
[CTA: comando + razão pra agir agora]
```

### Sequência
Cada e-mail tem UM objetivo (ver intake). Arco típico de 3:
- E-mail 1: cria desejo (mecanismo + cena), sem fechar.
- E-mail 2: prova + quebra de objeção via "Mesmo que…".
- E-mail 3: urgência + CTA forte (door metaphor opcional).

Cada e-mail usa um arquétipo de abertura diferente.

## Passo 3: CTA

1. Comando físico: "Aperta no botão aqui embaixo"
2. Razão pra agora: "porque [contexto real]"
3. Nomeação do destino sem soar venda: "te mando o vídeo"

## Passo 4: Production bar (exit gate)

- [ ] Passa no blocklist rápido (em-dash, palavras-vício, "não é X é Y")
- [ ] 1 CTA forte, não 3 difusas
- [ ] Mecanismo nomeado (se aplicável)
- [ ] Prova específica ou placeholder explícito
- [ ] Primeira linha do corpo ganha a segunda
- [ ] Estrutura aberta pra receber o assunto depois

## Fase 4: Assunto (DEPOIS do corpo)

Gere 5 assuntos, cada um inspirado num arquétipo diferente. Consulte "Padrões de Abertura" e "Mecânicas de Voz" na [dna/disguise.md](../dna/disguise.md).

Regras:
- Curiosidade real, sem clickbait vazio ("Descubra o segredo").
- Minúscula no estilo conversa funciona bem na caixa de entrada.
- Sem Title Case, sem "!", sem CAPS.
- Específico bate genérico: número quebrado, cena, contradição.

Apresente os 5 e deixe o usuário escolher.
