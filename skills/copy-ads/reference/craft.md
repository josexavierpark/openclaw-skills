# Fase 04: Craft (execução do script, sem hook ainda)

Escreve o **corpo** do anúncio. O hook final é gerado depois pela fase 05. Aqui você escreve com abertura em rascunho/placeholder.

## Princípio

Não trave o copy inteiro na primeira frase. Escreva o corpo persuasivo com base no blueprint adaptado da fase 03. A abertura final vem na fase 05, escolhida entre 5 variações inspiradas em exemplares diferentes do swipe.

## Sequência obrigatória

### Passo 1: Declare o preflight

```
COPADS_PREFLIGHT: intake=pass disguise=loaded retrieval=pass blocklist=loaded mutation=open
```

### Passo 2: Releia o BRIEF_LOCK
Tenha todos os 5 campos em mente: nicho, produto, destino, avatar comportamento, formato, mecanismo.

### Passo 3: Releia o blueprint adaptado
Tenha os movimentos persuasivos em ordem + tom + palavras-âncora.

### Passo 4: Carregue mentalmente disguise.md
Não vá esquecer dos 4 critérios do Disguise Test antes de cada parágrafo.

### Passo 5: Escreva a Voice Lock Sentence

Antes de escrever o copy, escreva UMA frase descrevendo a voz desta peça específica:

```
VOICE LOCK: [tempo verbal] + [posição do leitor: herói/testemunha/cúmplice] + [adversário: nomeado/interno/ausente] + [registro: bar/conversa/conselho/palco] + [origem do narrador: 1ª pessoa vivendo/3ª pessoa relatando/diálogo]
```

Exemplo:
```
VOICE LOCK: Presente + passado recente. Leitor como testemunha que vira protagonista. Adversário: algoritmo do Meta pós-atualização de abril. Registro de bar, sem distância. Narrador em 1ª pessoa relatando ontem.
```

Essa frase é seu guardrail durante todo o craft.

### Passo 6: Escreva o corpo do copy contra o blueprint

Siga os movimentos do blueprint adaptado na ORDEM. Cada movimento vira um parágrafo (ou bloco curto em vídeo).

**Regras durante a escrita:**
- Abertura em RASCUNHO/placeholder (será refinada na fase 05). Use `[HOOK]` como marcador ou escreva uma versão simples só pra fluir.
- Cada frase ganha a próxima. Sem boa vontade do leitor.
- Burstiness: alterne frase curta com longa. Use fragmentos.
- Adjetivos: corte os decorativos. Só os que servem ao argumento.
- Especificidade: número quebrado > número redondo. Situação concreta > adjetivo abstrato.
- Mecanismo: sempre nome chiclete sensorial (não SIGLA).
- Prova: nome + idade + situação + número, ou nada.
- CTA: comando específico + razão para agir agora + nomeação do destino sem soar como venda.

### Passo 7: Verifique o production bar antes de declarar "pronto"

Production bar (exit gate):

- [ ] Passa no Disguise Test (3 de 4 critérios)
- [ ] Passa no blocklist scan rápido (será checado formal na fase 08, mas faça leitura rápida)
- [ ] Se o brief usa adversário externo: nomeado e específico (não "o mercado")
- [ ] CTA não cita VSL/aula como produto. Usa referência indireta ("esse vídeo", "essa explicação", "esse teste")
- [ ] Nenhuma menção a valor monetário
- [ ] Leu em voz alta mental sem tropeçar
- [ ] Primeira frase do corpo ganha a segunda sem depender de boa vontade
- [ ] Estrutura clara pra receber o hook depois (não tem dependência interna que trave a abertura)
- [ ] Mecanismo nomeado (se aplicável)
- [ ] Prova específica (se aplicável)

Se algum item falhou, reescreva a parte específica.

### Passo 8: Marque a posição do hook

No copy entregue na fase 04, deixe explícito onde o hook vai entrar:

```
[HOOK FINAL DA FASE 05 ENTRA AQUI]

[Corpo do copy começa aqui]
```

Isso garante que a fase 05 sabe onde encaixar.

## Anti-padrões durante o craft

### Não comece pelo produto
RUIM: "Esse curso vai mudar sua vida." (cita o produto antes do problema)
BOM: começa em uma cena específica ou no problema dimensionado.

### Não use lista de benefícios abstratos
RUIM:
- Aprenda como ficar rico
- Descubra o segredo do sucesso
- Entenda por que você não está chegando lá

BOM: integre os benefícios na narrativa. Se precisar de lista, cada item com número ou situação concreta.

### Não use "imagine que..."
RUIM: "Imagine acordar todo dia com energia."
BOM: cena passada recente com gatilho sensorial concreto.

### Não termine com reafirmação da tese
RUIM: "E é por isso que esse método funciona."
BOM: termine em ação, pergunta aberta, ou comando direto.

### Não use voz passiva em frases de venda
RUIM: "Resultados foram obtidos por nossos alunos."
BOM: "Aluno meu (Carlos, 47, mecânico em SP) saiu de 0 pra 8 vendas em 3 semanas."

## Estrutura típica de copy longa por formato

### Copy longa feed (400+ palavras)

```
[HOOK FINAL DA FASE 05] (1-2 frases)

[Movimento 1: estabelecimento de cena ou tensão] (2-4 frases)

[Movimento 2: complicação/revelação do problema real] (3-6 frases)

[Movimento 3: mecanismo nomeado] (2-4 frases com nome chiclete)

[Movimento 4: prova nominal específica] (2-4 frases com pelo menos 1 testemunho ou case com nome + número)

[Movimento 5: antecipação de objeção via Sócio Cético ou similar] (opcional, 2-3 frases)

[Movimento 6: ponte para destino] (2-3 frases)

[CTA com nomeação indireta + razão pra agora] (1-2 frases)
```

### Copy curta feed (até 200 palavras)

```
[HOOK] (1 frase)

[Tensão + situação] (2-3 frases)

[Mecanismo OU prova específica] (1-2 frases)

[CTA] (1 frase)
```

### Roteiro vídeo curto (15-30s)

```
[Segundo 0-3: HOOK visual + auditivo]

[Segundo 3-15: TENSÃO/PROBLEMA com cena específica]

[Segundo 15-25: REVELAÇÃO/MECANISMO]

[Segundo 25-30: CTA direta]
```

### Roteiro vídeo médio (60-90s)

```
[0-5s: HOOK]

[5-20s: ESTABELECIMENTO DE CENA + PROBLEMA]

[20-40s: REVELAÇÃO DO MECANISMO + DIFERENCIAÇÃO]

[40-60s: PROVA NOMINAL]

[60-75s: ANTECIPAÇÃO DE OBJEÇÃO]

[75-90s: CTA + URGÊNCIA]
```

### Carrossel (texto por card)

```
Card 1: HOOK + cena
Card 2-3: PROBLEMA dimensionado
Card 4-5: MECANISMO + diferenciação
Card 6-7: PROVA + testemunho
Card 8: CTA
Card 9 (opcional): PS
```

## Como referir ao destino (CRÍTICO)

Nunca diga "curso", "treinamento", "programa", "produto". Use:

| Destino do BRIEF_LOCK | Como chamar no copy |
|---|---|
| VSL longa | "essa apresentação completa", "esse vídeo", "essa explicação" |
| VSL curta / mini-VSL | "esse vídeo rápido", "essa demonstração de 5 minutos" |
| Quiz | "esse teste", "essa avaliação rápida", "esse diagnóstico de 3 perguntas" |
| Teste de avaliação | "essa avaliação", "esse diagnóstico" |
| Página de captura (lead magnet) | "esse material", "esse passo a passo", "esse guia" |

## Como construir CTA

Estrutura mínima:

1. **Comando específico:** "Aperta no botão azul aqui embaixo"
2. **Razão pra agora:** "porque [contexto temporal real]"
3. **Nomeação indireta do destino:** "e te mando o vídeo agora"

Exemplos completos:

- "Toca no link aqui embaixo. Te mando o vídeo agora. Vou tirar do ar amanhã porque o limite que combinei com o Banco Central é 1.500 visualizações."
- "Aperta saiba mais aqui embaixo pra ver esse diagnóstico de 3 perguntas. Em 60 segundos você sabe se essa estratégia funciona pro seu corpo."
- "Clica no link da bio pra essa apresentação. Vou deixar até quinta porque depois disso o método muda."

NUNCA:
- "Clique aqui pra saber mais"
- "Garanta sua vaga agora"
- "Comece sua transformação"
- "Adquira agora"
