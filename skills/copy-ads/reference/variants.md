# Fase 06: Variants (3 versões com estruturas diferentes)

Gera 3 versões completas (script + hook) do mesmo brief, cada uma puxando **um exemplar diferente do swipe** como referência estrutural.

## Princípio

Diferente da fase 05 (que gera 5 hooks pro MESMO script), aqui geramos 3 anúncios estruturalmente DISTINTOS. Cada um tem:
- Estrutura persuasiva diferente
- Hook diferente
- Origem em exemplar diferente do swipe
- Mesmo BRIEF_LOCK

Útil pra A/B test estrutural, não só de abertura.

## Quando usar

- Aluno pediu "me dá 3 variantes pra testar"
- Aluno aprovou um copy e quer alternativas estrutural-mente diferentes pra escalar campanhas
- Aluno está rodando teste agressivo e quer 3 caminhos diferentes ao mesmo tempo

## Sequência obrigatória

### Passo 1: Releia o BRIEF_LOCK
Mesmo brief, 3 caminhos diferentes.

### Passo 2: Abra swipe/_index.md
Selecione 3 exemplares com ESTRUTURAS PERSUASIVAS DISTINTAS.

**Critério crítico:** os 3 exemplares precisam ter blueprints genuinamente diferentes. Não 3 versões da mesma estrutura.

Exemplos de combinações válidas:
- A: SAU-022 (In Media Res cena MMA) / B: SAU-009 (Myth-Busting médico) / C: SAU-013 (Entrevista tribal)
- A: DIV-003 (Confronto direto + projeção futuro) / B: DIV-002 (Entrevista milionário) / C: DIV-011 (Inventor story)
- A: SAU-001 (Contradição-impossibilidade narrativa) / B: SAU-006 (Vilão externo anatômico) / C: SAU-020 (Authority + ataque ao sistema)

Exemplos de combinações ERRADAS:
- A: SAU-002 (Bait & Pivot) / B: SAU-005 (Bait & Pivot) / C: SAU-024 (Bait & Pivot) — todas mesma estrutura
- A: SAU-008 (Luna Via) / B: SAU-014 (Luna parasite) / C: SAU-022 (MMA Luna) — todas micose, estruturas próximas demais

### Passo 3: Para cada exemplar selecionado

Adapte a estrutura persuasiva pro brief atual. Gere:
- Voice Lock Sentence específica daquela variante
- Script completo seguindo a estrutura daquele exemplar
- Hook usando o exemplar como referência de abertura

### Passo 4: Verifique production bar de cada variante

Cada uma das 3 tem que passar individualmente:
- Disguise Test
- Blocklist scan
- Sem menção a valor
- CTA com nomeação indireta
- Burstiness adequada

### Passo 5: Verifique zero overlap entre as 3

Regra: nenhuma frase ou expressão deve aparecer em mais de uma variante. Se aparecer, reescreva uma das duas.

### Passo 7: Pergunte ao aluno qual eixo interessa explorar

```
Qual variante mais te interessa pra iterar? Posso:
- Refinar uma específica
- Gerar 5 hooks alternativos pra cada uma
- Trocar 1 das variantes por outra estrutura
- Fazer audit técnico das 3
```

## Regras

- Cada variante referencia um exemplar diferente
- Estruturas precisam ser genuinamente diferentes (squint test: se você comparar lado a lado, conseguiria identificar a diferença estrutural em 5 segundos?)
- Todas passam no mesmo production bar
- Zero overlap de frases entre as 3
- Hooks também diferentes (cada um inspirado no exemplar correspondente, não troca de hook entre variantes)

## Como escolher 3 exemplares estrutural-mente distintos

### Padrão sugerido por nicho

**Saúde — emagrecimento:**
- A: SAU-002 (Bait & Pivot vinagre→azeite, lista de mecanismos)
- B: SAU-004 (Entrevista revelação 42 anos)
- C: SAU-012 (Myth-busting Gundry com avalanche de mitos)

**Saúde — sono / energia:**
- A: SAU-009 (Myth-busting médico inflamação crônica)
- B: SAU-013 (Entrevista tribal Elder Bruno)
- C: SAU-011 (Contradição impossibilidade pai 79 anos)

**Saúde — audição:**
- A: SAU-018 (Contradição 78 ouvindo como 27 + aula técnica)
- B: SAU-021 (Confissão vulnerável + whiteboard pedagógico)
- C: SAU-025 (100 reasons exhaustion list)

**Diversos — renda extra:**
- A: DIV-002 (Entrevista milionário aos 22)
- B: DIV-003 (Confronto direto + projeção arrependimento)
- C: DIV-001 (Myth-busting credit score, escala financeira)

**Diversos — eletrônicos casa:**
- A: DIV-005 (Contradição 90s + inventor story NASA)
- B: DIV-006 (Contradição 3min + inventor avós blackout)
- C: DIV-011 (Confronto + inventor Silicon Valley pivô)

### Se nicho não tem 3 exemplares próximos

Misture nichos. Pegue 1 do mesmo nicho + 2 de nichos diferentes com estruturas compatíveis. Exemplo:

Brief = micose unha (3 exemplares disponíveis: SAU-008, SAU-014, SAU-022, mas todos com estruturas parecidas)

Combinação melhor:
- A: SAU-022 (MMA Story In Media Res específico de micose)
- B: SAU-006 (Vilão externo anatômico aplicado de SI joint pra micose)
- C: SAU-009 (Myth-busting médico aplicado de grounding pra micose)

A estrutura do exemplar B e C migra mesmo sendo de outro subnicho.

## Anti-padrões em variants

### 3 variantes com mesmo hook trocando palavra
RUIM: 3 versões com "comecei a notar que..." trocando apenas o sintoma.
BOM: 3 hooks com estruturas retóricas distintas (declaração / cena / pergunta-revelação).

### 3 variantes com mesma arquitetura
RUIM: todas seguem hook → problema → mecanismo → prova → CTA na mesma ordem.
BOM: A pode ser hook → prova nominal → problema. B pode ser hook → cena → mecanismo → CTA. C pode ser hook → confronto → revelação tardia.

### Mecanismo idêntico em 3 variantes
RUIM: as 3 nomeiam "Protocolo das 5 Janelas".
BOM: A nomeia "Protocolo das 5 Janelas", B nomeia "Truque do Cortisol Reverso", C usa narrativa sem nome chiclete (porque o exemplar C não usa).

Se o brief tem mecanismo fixo do produto, mantenha o mesmo nas 3 variantes. Mas a forma de APRESENTAR o mecanismo deve mudar.

### Tom idêntico em 3 variantes
RUIM: as 3 escritas em registro "amigo de bar".
BOM: A pode ser registro confessional, B narrativo terceira pessoa, C confrontativo direto.

## Como dividir o trabalho mental

Para gerar 3 variantes eficientemente:

1. Escolha os 3 exemplares ANTES de começar a escrever.
2. Escreva a Voice Lock Sentence de cada uma. Compare lado a lado — são suficientemente diferentes? Se não, troque um exemplar.
3. Escreva o hook de cada uma. Compare — são suficientemente diferentes? Se não, refaça.
4. Escreva o corpo de cada uma. Compare frase por frase contra as outras 2 — algum overlap? Refaça.
5. Verifique production bar individual.
6. Apresente lado a lado pro aluno.

## Custo de tokens

Variants triplica o output. Cada variante completa = ~500-800 palavras. 3 variantes = ~1500-2400 palavras só de script. Mais blueprints. Mais audit. Reserve max tokens output adequado (4000-8000) na config do assistente.
