# Briefing Vazio: Template Padrão de Cada Playbook

> Esqueleto usado pela skill ao criar cada arquivo de playbook no briefing.

---

## Template para cada playbook (XX-NomeDoPlaybook.md)

```markdown
# {NN}. {Nome do Playbook}

> Status: em andamento / completo / pendente
> Última atualização: YYYY-MM-DD HH:MM

## {Seção 1 do template do playbook}

{resposta salva pelo usuário, escolhida do banco ou preenchida manualmente}

## {Seção 2 do template do playbook}

{resposta salva}

...

## Validação (checklist)

- [x] item validado
- [ ] item pendente

## Notas / Ideias soltas

{coisas que o usuário comentou mas não viraram resposta formal}
```

---

## CONTEXTO INICIAL (00-CONTEXTO.md)

```markdown
# Contexto do Produto

> Briefing iniciado em: YYYY-MM-DD
> Versão do sistema: v1.0

## Identificação

- **Nome do produto / oferta:**
- **Tipo:** Suplemento / Infoproduto / Serviço / SaaS / Outro
- **Nicho macro:** Saúde / Beleza / Dinheiro / Relacionamento / Performance / Outro
- **Sub-nicho específico:**
- **Ticket pretendido:** Low (até R$ 197) / Médio (R$ 197-997) / High (R$ 997-5000) / Premium (acima 5000)

## Promessa em uma frase

(O que ele promete e para quem)

## Por que estou criando essa oferta agora

(motivação, contexto, oportunidade detectada)

## Restrições / limitações conhecidas

(legais, técnicas, de tempo, de orçamento)

## Materiais já produzidos

(VSLs anteriores, anúncios, depoimentos, estudos de cliente, etc.)

## Avatar inicial (rascunho, será aprofundado no Playbook 01)

- Faixa etária:
- Gênero predominante:
- Renda:
- Maior dor:
- Maior desejo:
```
