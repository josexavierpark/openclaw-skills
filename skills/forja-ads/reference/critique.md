# Critique (scoring do copy)

Avalia o copy gerado contra 10 heurísticas, 0-4 cada. Não é review solto, é tabela com nota. Consulte [dna/disguise.md](../dna/disguise.md) para as 7 alavancas.

## As 10 heurísticas

| # | Heurística | Como pontuar |
|---|---|---|
| 1 | Voz validada | 0 = blocão acadêmico, 4 = fala com momentum nos 11 marcadores de [estilo.md](estilo.md), espelhando o ritmo do doador |
| 2 | Hook/abertura | 0 = genérico, 4 = passa Blob + Bar + Memória |
| 3 | Especificidade | 0 = abstrato, 4 = 3+ âncoras (número quebrado, prazo, cena, nome) |
| 4 | Mecanismo nomeado | 0 = "esse método", 4 = nome chiclete em aspas usado consistente |
| 5 | Fidelidade estrutural | 0 = estrutura traída ou blocos órfãos, 4 = cada bloco cumpre a função do rótulo (modos de reescrita) / segue o blueprint do swipe (criação) |
| 6 | Protagonismo do leitor | 0 = "nós oferecemos", 4 = "você" em cada frase de valor |
| 7 | Ângulo no comando | 0 = ângulo só na 1ª frase, 4 = lente governa corpo, prova e CTA |
| 8 | Segunda metade | 0 = CTA nu, 4 = CTA com valor + transição + bullets + 2º CTA na ordem certa (quando o modo pede) |
| 9 | Prova específica | 0 = "muitos alunos", 4 = nome+idade+situação+número (ou placeholder declarado) |
| 10 | Zero reflexos de IA | 0 = 5+ hits no blocklist, 4 = zero |

## Procedimento

1. Leia o copy. 2. Pontue cada heurística com 1 linha de justificativa. 3. Some.

| Score | Banda | Ação |
|---|---|---|
| 35-40 | Excepcional | Liberar |
| 28-34 | Pronto | Liberar + 1-2 melhorias |
| 20-27 | OK | Liberar + 3-4 melhorias |
| <20 | Crítico | Reescrever |

## Red flags por persona

- **Cético (nível 3 de consciência):** promessa sem âncora? prova sem nome? mecanismo sem novidade?
- **Scroll no ônibus:** primeira frase segura o dedo? benefício enterrado no 4º parágrafo?
- **Fiscal de anúncio:** parece anúncio? cheira a copywriter? (o anúncio nunca pode parecer anúncio)

## Saída

```
CRITIQUE (X/40)
[10 heurísticas com nota + justificativa de 1 linha]
Banda: [...]
Red flags: [...]
Melhorias prioritárias: [até 3]
```

Não infle. Copy real tira 28-32. Justifique cada nota. Nos modos multi-peça (10 hooks, 5 variações), pontue o conjunto e aponte a peça mais fraca.
