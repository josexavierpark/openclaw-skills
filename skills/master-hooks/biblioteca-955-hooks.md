## COMO USAR ESTA BIBLIOTECA

### Para Gerar Hooks Rapidamente
1. Identifique o NICHO e o GATILHO PSICOLÓGICO mais adequado
2. Selecione 5-10 templates da categoria correspondente
3. Preencha os placeholders com os elementos do seu produto/oferta
4. Aplique os 9 elementos para fortalecer cada hook
5. Use o Processo Dial Back para calibrar a intensidade
6. Avalie com os 3 filtros (Blob, Bar, Memória)

### Para Modelar Hooks Existentes
1. Identifique a PSICOLOGIA do hook original (qual gatilho usa?)
2. Encontre o template mais próximo nesta biblioteca
3. Substitua os elementos superficiais mantendo a estrutura psicológica
4. Crie 3-5 variações
5. Teste e escale o vencedor
