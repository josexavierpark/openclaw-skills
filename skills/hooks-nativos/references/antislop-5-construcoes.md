# As 5 Construções Retóricas Proibidas (+ bônus)

5 construções que IA produz em loop e que IMEDIATAMENTE denunciam texto artificial. Mais 1 bônus (repetição paralela). Proibição absoluta em qualquer fase da skill.

Fonte: `AI-Research/ai-tells-deep-research.md` Seção 11.

---

## Construção 1: Elliptical Setup (Pergunta Implícita)

### Definição
Fragmento retórico que cria ritmo artificial com interrogação implícita sem resposta imediata.

### Padrão proibido
```
"A melhor parte? Você não precisa fazer nada."
"O único limite? O céu."
"A parte boa? Funciona enquanto você dorme."
"O segredo? Constância."
"A verdade? Ninguém te ensinou direito."
```

### Por que falha
- Ritmo artificial
- Setup fragmentado denota IA
- Avatar percebe como manipulação retórica

### Correção
Afirme diretamente, sem o setup:
```
✔️ "Você não precisa fazer nada."
✔️ "O céu é o limite."
✔️ "Funciona enquanto você dorme."
✔️ "O segredo é constância."  (ou melhor: "Constância é o que diferencia.")
```

## Construção 2: Revelation Hook (Segredo Revelado)

### Definição
Posiciona o texto como expondo verdade que "ninguém fala". Pseudo-confidência manipuladora.

### Padrão proibido
```
"Aqui está a verdade que ninguém fala sobre [X]..."
"O que ninguém te conta sobre [X] é..."
"Isso que vou te contar ninguém admite..."
"A verdade impopular que ninguém quer assumir é..."
"Ninguém quer falar sobre isso, mas..."
"Os 'experts' não querem que você saiba que..."
```

### Por que falha
- Manipulação genérica
- Suposição falsa de que o leitor será surpreendido
- Sem prova específica, vira clickbait

### Correção
Apresente a informação como observação direta ou cruel:
```
✔️ "Ninguém ganha 10k em 30 dias. Inclusive eu."
✔️ "Tem 3 brechas legais pro MEI que economizam 40% do DAS."
✔️ "A maioria dos nutricionistas ainda usa tabela de 1992."
```

## Construção 3: The Big Contrast (Grande Contraste)

### Definição
Variante institucional do "Não é X, é Y". Toma premissa e inverte com "grande insight".

### Padrão proibido
```
"Não é automação, é amplificação."
"Não é dados, são decisões melhores."
"Não é velocidade, é momentum."
"Não é só performance, é qualidade de vida."
"Não é só sobre X, é sobre Y."
"Isso não é X. É Y."
```

### Por que falha
- Dicotomia falsa
- Estrutura IA universal queimada
- Cross-reference com memória `feedback_evitar_nao_e_x_e_y.md`: PROIBIÇÃO ABSOLUTA do usuário

### Correção
Afirme apenas o positivo:
```
✔️ "É amplificação. Você multiplica sua capacidade sem multiplicar sua hora."
✔️ "Dados viram decisão quando você sabe ler."
✔️ "Momentum compõe quando velocidade não consegue."
```

## Construção 4: The Great Reframe (Grande Reframe)

### Definição
Enuncia verdade universal e inverte com moral "mais profunda". Pseudo-filosófico.

### Padrão proibido
```
"Todo mundo corre atrás de atenção. Poucos ganham confiança."
"Velocidade não vence. Momentum vence."
"As pessoas querem respostas. Mas lembram histórias."
"Sucesso não é mais. É o suficiente."
"O mundo ensina X. Mas a vida exige Y."
```

### Por que falha
- Antítese forçada
- "Moral superior" é padrão de IA pós-RLHF
- Soa como tweet pseudo-intelectual

### Correção
Um pensamento coerente e direto, sem oposição equilibrada:
```
✔️ "Confiança ganha jogo. Atenção só ganha clique."
✔️ "Momentum compõe juros que velocidade nunca paga."
✔️ "Histórias grudam onde respostas escorregam."
```

Note: pode usar 2 frases curtas, mas a 2ª não pode ser "moral superior". Tem que ser **consequência prática** da 1ª.

## Construção 5: Philosophical Reduction (Redução Filosófica)

### Definição
Reduz ideia grande a contradição poética. Soa como tweet pseudo-intelectual ou frase de Linkedin.

### Padrão proibido
```
"IA não está substituindo pessoas, está substituindo a espera."
"Confiança não é barulho, é consistência silenciosa."
"Sucesso não é mais. É o suficiente."
"Liberdade não é ter mais escolhas. É saber qual importa."
"O futuro não é o que vem. É o que você constrói agora."
```

### Por que falha
- Paradoxo poético é marca de RLHF que prioriza elegância sobre clareza
- Soa profundo mas não é acionável
- Avatar percebe como esvaziado

### Correção
Descreva o conceito diretamente, sem paradoxo:
```
✔️ "IA acelera o que você esperava 3 dias pra receber. Esse é o ganho real."
✔️ "Consistência silenciosa cria confiança que barulho não consegue."
✔️ "O suficiente que dorme tranquilo vence o 'mais' que perde sono."
```

## Bônus: Repetição Retórica Paralela

### Definição
Sequências de orações paralelas que acumulam o mesmo ponto sem agregar.

### Padrão proibido
```
"Eu durmo, e o dinheiro chega. Eu acordo, e o dinheiro chegou."
"Não é sorte. Não é herança. Não é família rica."
"Não foi destino. Não foi acaso. Não foi sorte."
```

### Por que falha
- Paralelismo triplo = ritmo regular = low burstiness detectável
- Acumula sem agregar informação nova

### Correção
Compacte. Use **uma** afirmação que cobre o ponto:
```
✔️ "Nunca foi sorte nem herança."
✔️ "Não foi sorte. Foi rotina."  (2 frases, com consequência prática)
```

## Resumo operacional pra Fase 6

Ao auditar cada par falado + texto na tela, procure por:

| Construção | Sinal típico | Correção |
|---|---|---|
| Elliptical Setup | Fragmento + interrogação | Tirar o setup |
| Revelation Hook | "verdade que ninguém fala" | Apresentar a info direto |
| Big Contrast | "Não é X, é Y" em qualquer forma | Afirmação positiva |
| Great Reframe | 2 frases com "moral superior" | 1 frase ou 2 com consequência prática |
| Philosophical Reduction | Paradoxo poético "X não é A, é B" | Descrição direta |
| Repetição paralela | 3+ negativas em série | Compactar em 1 afirmação |

**Regra crítica:** se identificar qualquer das 6, **reescreva**. Não tente "suavizar". Essas construções têm assinatura de IA tão forte que mesmo versão atenuada delas dispara o tell.
